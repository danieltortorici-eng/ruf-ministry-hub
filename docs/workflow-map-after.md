# Calm OS Workflow Map — After

## Today

```text
Open Today
  -> Next thing to do
     -> Open / Do this
     -> Done
     -> Later
  -> Quick Capture
  -> After that (zero to two)
```

## Shared capture and proposal flow

```text
Today / Capture / profile / dictation / shared text / imported text
  -> one recoverable raw draft
     + optional locked person context
  -> Save for later
     OR Process
  -> persist raw capture before processing
  -> gather minimum approved context
  -> local parser or explicitly approved backend proposal
  -> upsert one proposal for the capture revision
  -> Suggested updates
  -> select / edit / reject / change person / mark sensitive
  -> Save approved updates
  -> idempotent local execution and one atomic save
```

AI or network failure preserves the capture as retryable and never auto-resends or partially writes structured records.

## People and profile

```text
People search
  -> tap whole compact card
  -> essential identity + care timing
  -> Right Now: Pray / Next thing / Remember / Reminder
  -> unified person capture
  -> Brief Me / Follow Up
  -> collapsed Profile Details
  -> separate bounded Notes / Meetings / Prayer / Follow-Ups / Timeline
```

## Navigation

```text
Today | Capture | People | Prayer | More
```

More preserves secondary tools, privacy, data safety, settings, and administration through disclosure rather than primary visual prominence.
