# Calm OS Workflow Map — Before

## Today

```text
Open Today
  -> scan up to eight competing sections
  -> compare Start Here and Autopilot recommendations
  -> choose from large action/list clusters
  -> enter a separate workflow
```

## Capture

```text
Today Quick Capture button
  -> open Quick Grab
  -> choose category and urgency
  -> save Quick Grab
  -> choose manual 23-control conversion or AI privacy gate
  -> AI Review
  -> final confirmation
  -> save selected records
```

Shared URL text reaches the Quick Grab draft, but category and urgency query parameters continue the classification-first contract.

## Profile

```text
People
  -> Open Profile button
  -> scan stats, field grid, timestamps, and 11 actions
  -> choose separate note / meeting / prayer / follow-up sheet
  -> save structured record directly
```

## Brief Me and Follow Up

```text
Profile action
  -> privacy gate
  -> create pending proposal
  -> leave profile for AI Review
  -> find the result
  -> copy or use it
```
